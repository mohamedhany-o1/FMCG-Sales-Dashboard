# FMCG Sales Analysis Dashboard

An executive Power BI dashboard tracking Sales, Quantity, Profit, Profit % and target achievement (Ach %) for an FMCG company.

## Dashboard Preview

<img width="2460" height="1392" alt="Screenshot 2026-11-24 113904" src="https://github.com/user-attachments/assets/8347e426-c97c-4786-9b2a-d80891647eed" />

## Key features
- KPI cards: Total Sales, Target, Quantity, Profit, Ach %, Profit %
- Trend, donut and bar charts by month, quarter, category, region and product
- Slicers for year, category, region and quarter
- Custom tooltip page

## Tools
Power BI, DAX

## Files
- `fmcg.pbix`: the Power BI report
- The Excel file: the source data (2,000 rows)
